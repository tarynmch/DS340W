# A Comparative Study of Machine Learning Models on Predicting Academic Outcomes 
The goal of this study is to understand the impact of open learning environment (OLE's) on student's academic success. We hope to alter the data to find the best combination of models and feature selection. 

## Installation Instructions
1. Download the assessments, studentaAssessment, studentInfo, studentRegistration, and vle csv files. Additionally, download FinalCode.ipynb
2. Go to this website: https://analyse.kmi.open.ac.uk/open-dataset. Download the studentVle data. (The data file was too large to upload to Github, so you need to do it individually).
3. Open FinalCode.ipynb file.
4. Navigate to the second code chunkand add the correct directories to where the downloaded the data.
5. Run all the code

## How to Use Project
This project contains importing & cleansing data, data merging & eda, machine learning methods on baseline data, and machine learning methods on augmented data. The layout of the code file to walk you through each section and describe the findings. You can find a full analysis in our final paper.
